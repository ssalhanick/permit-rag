# Session 2026-07-20 — Animated SVG Logo & Leonardo.ai Integration

## What was accomplished

- Added `frontend/src/assets/logo.svg` — properly grouped SVG with animated element IDs
  (`row1–3`, `check1–3`, `tool-brush`, `tool-hammer`, `tool-ruler` + `-bob` sub-groups)
- Created `frontend/src/components/LogoSVG.jsx` — SVG as a plain React component
  (no Vite plugin dependency). Accepts `animated` prop; IDs only rendered when `animated={true}`
  to prevent duplicate-ID conflicts between nav and hero instances
- Created `frontend/src/hooks/useLogoAnimation.js` — hook encapsulating all animation logic:
  `play(mode)` and `replay()`, two timing modes (`moderate` 3.2 s, `snappy` 1.32 s),
  `rowIn`, `toolIn`, `checkDraw`, `bob` keyframe wiring via `document.getElementById`
- Created `frontend/src/styles/logo-animations.css` — all logo keyframes + initial hidden states;
  imported by `styles.css`
- Updated `frontend/src/Nav.jsx` — replaced `<span>permit_rag</span>` with static `<LogoSVG>`
  using `nav-logo-themed` CSS class (dark/light palette override for dark nav background)
- Updated `frontend/src/LandingPage.jsx` — added `<LogoSVG animated>` hero above the badge pill;
  `useLogoAnimation.play('moderate')` fires on mount
- Updated `frontend/vite.config.js` — reverted to plain config (no SVGR plugins needed)
- Updated `frontend/src/styles.css` — added `@import` for logo-animations.css,
  `.nav-logo-themed` fill overrides, `.hero-logo` sizing + drop-shadow, `.site-nav-header min-height`
- **Replaced kickoff wizard chat with deterministic materials:**
  - Removed conversational chat wizard step in `ProjectKickoffPage.jsx` and replaced with a CheckboxGrid for "Materials & Scopes" using `MATERIAL_OPTIONS` in `projectPermitRules.js`.
  - Added `materials` JSONB array to `projects` database table via migration `021_project_materials.sql`.
  - Updated Pydantic request/response schemas in `api/schemas.py` and project CRUD functions in `db/client.py`.
- **Improved Kickoff Navigation & Transition Flow**:
  - Re-ordered the kickoff steps to match the requested flow: Rooms (spaces) → Work (workTypes) → Material (materials) → Scan (roomScan) → Name → Summary (confirm).
  - Updated `finishNavigation` to route users directly to `/projects/${projectId}/scans` if they selected "Yes, I want to perform a 3D scan".
- **Added Sticky and Automatic Project Context**:
  - Automatically save the active project ID to `localStorage` when creating or updating a project.
  - Updated `QueryPage.jsx` to load and default `activeProjectId` from `localStorage` if not provided via URL parameter, and sync manual context changes back to `localStorage` to keep the context sticky.
- **Integrated Leonardo.ai API for room preview images:**
  - Added `_leonardo_generate` helper to `commerce/room_image.py` to handle async generation and polling via Leonardo's REST API.
  - Implemented automatic check for `LEONARDO_API_KEY` with automatic fallbacks to `OPENAI_API_KEY` (if set) and solid mock PNG generation (offline).

  - Updated route tests and unit tests to mock and assert the new fallback flows.
  - Exposed `LEONARDO_API_KEY` to the ECS container definition via SSM parameter in `terraform/main.tf`.
- **Fixed Layout Squeezing on Query and Debug-Query pages**:
  - Removed duplicate Tailwind grid wraps (`grid-cols-1 lg:grid-cols-4`) inside `.query-page-layout` container, which was squeezing columns inside a narrow 280px left boundary on desktop.
  - Aligned HTML tags with `.query-page-sidebar` and `.query-page-main` classes defined in `styles.css` for a responsive, full-width desktop split and stacked mobile view.

## Decisions

| Decision | Choice |
|----------|--------|
| SVG rendering | Plain `LogoSVG.jsx` JSX component — avoids `@svgr/rollup` / `vite-plugin-svgr` version conflicts |
| Animation scoping | `animated` boolean prop — IDs only rendered on hero instance; prevents `getElementById` finding nav logo |
| Animation trigger | `useLogoAnimation` hook called in `LandingPage` on mount (`moderate` mode) |
| Nav logo | Static, no animation, themed fills via CSS class |
| Kickoff materials | Replaced freeform LLM chat step with a deterministic list of checkboxes |
| Room Image Generator | Primary: Leonardo.ai (with polling and `tiling` support); Fallbacks: OpenAI -> Offline Mock |
| Active Project Context | Stored in `localStorage` for sticky behavior across the query view |

## Blockers / Issues encountered

- `@svgr/rollup` — works for Rollup builds but Vite dev server bypasses it → `createElement` error
- `vite-plugin-svgr` — `transformWithEsbuild` deprecated in this Vite version → server error
- Duplicate IDs — both Nav and LandingPage rendered `LogoSVG` with same IDs; `getElementById` found Nav (first in DOM) instead of hero logo → fixed with `animated` prop
- AWS CLI Root Login 400 — resolved by logging in via Root User console to manually configure SSM parameter `leonardo_api_key`.
